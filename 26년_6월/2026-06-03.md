## Algorithm
- 수 나누기 (lv0) - 각자 다른 코드 스타일이 있고 좀 더 수학적으로 대단한 코드들이 있지만, 정석을 추구한다.
- 심폐소생술 (lv0) - enumerate을 사용하면 더 좋지 않았을까 하고 더 찾아보니 그것이 아니고, index를 사용해야 한줄 정리가 가능하다.

```Python
for action in cpr:
    answer.append(basic_order.index(action) + 1)
```

## CS-Study
- REST API 와 RESTFUL은 면접에서 CS 질문으로 자주 나온다.
- HTTP 메소드로 GET, POST, PUT, PATCH, DELETE가 있다.
- URI로 자원을 표현하고, HTTP 메소드로 행위를 정의하는 아키텍처 스타일이다.
- 동사를 사용하지 않고, 명사를 사용하며 소문자, 하이픈(-)을 사용한다.
- REST API 의 원칙을 잘 지키는 것이 RESTFUL 이다.
