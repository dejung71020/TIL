## CS-Study

- FastAPI는 구조를 강제하지 않기 때문에 규모에 맞는 아키텍처를 직접 선택해야 한다.
- 소규모는 Flat, 현업 표준은 Domain-based, 테스트 중심 대형 서비스는 Clean Architecture를 사용한다.
- Repository Pattern을 사용하면 Service가 DB에 직접 의존하지 않아 테스트 시 Mock 주입이 가능해진다.
- Generic CRUD Base를 만들면 도메인마다 CRUD를 반복 구현하지 않아도 된다.
- 표준 응답 모델과 전역 예외 처리를 적용하면 라우터마다 try/except를 반복할 필요가 없다.
- 현업에서 가장 많이 쓰는 조합: Domain-based + Repository Pattern + Generic CRUD + 표준 응답 모델 + 전역 예외 처리
